# Get webR R Version Information

Get webR R Version Information

## Usage

``` r
rw_r_version_info()
```

## Value

A list with components, e.g.

- x_y_z:

  Full R version string (e.g., "4.5.0")

- x_y:

  Major.minor version (e.g., "4.5")

- platform:

  Platform string (e.g., "wasm32-unknown-emscripten")
